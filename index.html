How to Use

Up and running in under a minute — no account, no EPG setup required.

1

Copy a Playlist URL

Hit Copy URL on a playlist card above. The link points straight to the live .m3u file hosted on GitHub Pages, so your player always loads the latest version.

2

Add It to Your Player

Open your IPTV app and choose Add Playlist / Open Network Stream / Remote playlist, then paste the URL. Or simply open the downloaded .m3u file in VLC.

3

Start Watching

Grab the remote, browse by category groups, and play. If a stream is down, try its duplicate entry — many channels are listed with multiple sources for backup.
