Open playlist from URL

Load a remote .m3u / .m3u8 playlist over http(s). The server must allow cross-origin requests (CORS).

Help & About

A lightweight, fully client-side viewer for .m3u / .m3u8 playlists. Files and URLs are parsed right in your browser — nothing is uploaded anywhere.

Opening a playlist

  • From a file — click 📁 Open playlist, or drag & drop a .m3u / .m3u8 file anywhere on the page.
  • From a URL — click 🔗 Open from URL and paste an http(s):// link, or drag a playlist link straight onto the page. The remote server must allow cross-origin requests (CORS).

Auto-opening with the open query parameter

Add ?open= to this page's address and the playlist is fetched automatically as soon as the page loads. The open parameter is then removed from the address bar, so a refresh will not load it again; any other query parameters are kept. The value may be plain or URL-encoded.

m3u-previewer.html?open=https://example.com/playlist.m3u

Only http:// and https:// URLs are accepted.

Search & filters

  • Press / to jump to the global search box; Esc clears it.
  • Each column header has its own filter input (Esc clears the focused one; Enter dismisses it).
  • Once anything is filtered, the ✖ Clear filters button appears — one click resets the search and every column filter.

Table

  • Click a column title to sort; click again to reverse the order.
  • Drag the thin handle on a header's right edge to resize that column (desktop only); double-click the handle to restore its default width. Your layout is remembered.
  • Click any URL cell to copy it to the clipboard.
  • Large playlists are rendered virtually — only the rows currently in view exist in the page, so even 20,000-channel lists scroll and filter smoothly.

Appearance

  • 🌙 / ☀ toggles dark and light mode; the choice is remembered.
